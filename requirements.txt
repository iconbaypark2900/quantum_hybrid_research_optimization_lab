# Dependencies live in pyproject.toml, which is the single source of truth.
#
# This file is a shim so that `pip install -r requirements.txt` keeps working.
# It deliberately does not restate the dependency list: an earlier version of
# this repository carried two manifests that disagreed, and the divergence
# between them was the largest set of claims the code did not back.
#
# Installing this way also enforces requires-python (>=3.10,<3.12), so an
# attempt on 3.12+ fails at install with a message naming the interpreter
# rather than producing six confusing ZNE failures later.

-e .[test]
